# Lista de Tareas Interactiva con Temas Claro y Oscuro

Esta es una aplicación web interactiva de lista de tareas que permite a los usuarios agregar, 
marcar como completadas y eliminar tareas.

## Funcionalidades Principales

* Agregar nuevas tareas.
* Marcar tareas como completadas.
* Eliminar tareas.
* Persistencia de tareas con localStorage.

## Cómo Utilizar

1.  Abre el archivo index.html en el navegador.
2.  Escribe tu tarea y presiona Enter o el botón de agregar.
3.  Haz clic en el checkbox para completar una tarea.
4.  Haz clic en el icono de la papelera para eliminar una tarea.

## Tecnologías Utilizadas

* HTML
* CSS
